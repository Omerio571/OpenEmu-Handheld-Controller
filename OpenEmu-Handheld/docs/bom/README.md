# Bills of Materials

This directory contains bills of materials (BOMs) for OpenEmu Handheld prototypes.

Each BOM records the parts used for a specific prototype, including purchase quantity, quantity used, cost, purpose, and supplier links. Prices are recorded as development references and may change over time.
