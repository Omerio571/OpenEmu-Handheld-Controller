# Prototype Documentation

This directory contains documentation for physical OpenEmu Handheld prototype builds.

Prototype documentation may include:

- prototype goals
- concept sketches
- full-size mock-ups
- physical layout
- electronics layout
- wiring concepts
- assembly information
- known limitations
- testing notes
- revision decisions
- links to the hardware, firmware, and software used by the prototype

Prototype documentation describes how the different parts of the project are combined into a working prototype.

Part revisions are tracked independently. A part can be revised even after it functions if its tolerances, alignment, mechanical stress, cable clearance, serviceability, or compatibility with later parts could create downstream problems.

The actual source and project files remain in their appropriate repository directories:

- `hardware/` for CAD and electronics design files
- `firmware/` for microcontroller firmware
- `software/` for applications and system software
- `media/` for project images, diagrams, photographs, and renders
- `docs/bom/` for bills of materials
