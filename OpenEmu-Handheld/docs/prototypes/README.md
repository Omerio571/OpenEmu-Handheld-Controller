# Prototype Documentation

This directory contains documentation for physical OpenEmu Handheld
prototype builds.

Prototype documentation may include:

- prototype goals
- concept sketches
- physical layout
- electronics layout
- wiring concepts
- assembly information
- known limitations
- testing notes
- links to the hardware, firmware, and software used by the prototype

Prototype documentation describes how the different parts of the project
are combined into a working prototype.

The actual source files remain in their appropriate repository directories,
such as:

- `hardware/` for CAD and electronics design files
- `firmware/` for microcontroller firmware
- `software/` for applications and system software
- `media/` for project images, diagrams, photographs, and renders
- `docs/bom/` for bills of materials
