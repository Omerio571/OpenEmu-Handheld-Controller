# Security Policy

OpenEmu Handheld is currently an experimental hardware project and does not yet have a stable software release.

## Reporting a Security Issue

If you discover a security issue in future firmware, software, USB communication, update mechanisms, or network services, please report it privately to the project maintainer rather than publishing exploit details immediately.

Until a dedicated security contact is added, open a GitHub issue containing only a minimal description and request a private contact method. Do not post secrets, private keys, credentials, or weaponized exploit code.

## Hardware Safety

This project may involve:

- Lithium-ion / lithium-polymer batteries
- USB power delivery
- Charging circuits
- Custom PCBs
- Heat-generating processors
- 3D-printed structural parts

Prototype designs should be treated as experimental. Verify polarity, current limits, thermal behavior, insulation, and battery protection before use.
