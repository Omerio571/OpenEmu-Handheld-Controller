# Third-Party Software and Trademarks

OpenEmu Handheld is designed to work with independent third-party software and hardware ecosystems.

Possible external software may include emulator projects, Linux distributions, Android, graphics drivers, controller libraries, and other open-source or proprietary tools.

## Important Rules

- Third-party software is not automatically covered by this repository's license.
- Do not copy emulator source code into this repository unless its license permits it and attribution requirements are followed.
- Prefer documenting installation or integration rather than redistributing third-party binaries.
- Keep each dependency's license notices intact.
- Do not upload commercial game ROMs, console firmware, encryption keys, BIOS files, or copyrighted game assets.
