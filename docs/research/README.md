# Research Notes

Use this directory for technical research that directly affects design decisions.

Suggested topics:

- USB 2.0 display bandwidth
- Raw vs compressed framebuffer transport
- HDMI / USB bridge chips
- ARM SBC / SoM benchmarks
- 2 GB vs 4 GB RAM testing
- Native-resolution emulation
- Thermal testing
- Battery runtime
- Display latency
- Controller latency

Each research note should ideally include:

- Question being tested
- Hardware / software setup
- Test method
- Measurements
- Result
- Design decision
- Links to public sources where applicable
