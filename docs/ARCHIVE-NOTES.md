# Archive integration notes

This repository was assembled from `OpenEmu-Handheld(3).zip` and `Controller Files For LEft and Right Side.zip`, plus the images present in this conversation and a historical Arduino serial sketch shared in chat.

The older archives mentioned in earlier conversations were **not available as ZIP attachments in this turn**; they were not independently imported. Historical files already present in the supplied repository and controller archive were preserved. Exact duplicate binary files were not duplicated, with their archive filenames recorded in `archive-duplicates.csv`. Original CAD export filenames remain unchanged.

Native design files and exported meshes aren't necessarily interchangeable: review in Fusion 360 / slicer before printing. No new STEP files were generated.
