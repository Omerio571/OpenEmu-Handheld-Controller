# Left-side controller

CAD is grouped by format: `source/` native Fusion 360, `printable/` 3MF, `interchange/` OBJ/MTL/FBX/DXF. Original designer filenames are retained to avoid falsely assigning revisions.

**Latest supplied revision:** `LeftSide V15 .3mf` (`printable/`) with accompanying `LeftSide V15 .obj` (`interchange/`). V15 was reportedly being printed; the final electrical result was not yet confirmed.

Archived designs include V5, V9–V12 and multiple redo experiments. Some exports have uncertain revision relationships. See `../../docs/prototypes/controller-fabrication.md`.

OBJ exports should stay alongside matching MTL files where supplied. Refer to `../../docs/cad-inventory.csv` for the exact archive/file inventory.
