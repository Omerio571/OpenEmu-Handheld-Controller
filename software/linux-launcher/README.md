# Linux Launcher

Planned standalone V3 frontend.

Goals:

- Boot directly into a console-like interface.
- Launch installed emulators.
- Apply a performance profile before gameplay.
- Stop nonessential services where safe.
- Restore services after emulator exit.
- Support clean shutdown and recovery.
- Avoid unnecessary desktop/background software.

The launcher should treat emulator executables as external dependencies unless their licenses permit redistribution.
