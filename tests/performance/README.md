# Performance Testing

For each emulator / board test, record:

- Board / SoC
- RAM capacity
- OS
- Kernel
- Graphics driver
- Emulator version
- Game or legal test workload
- Internal resolution
- Frame-rate target
- Average FPS
- 1% low FPS if available
- CPU utilization
- GPU utilization
- RAM usage
- Swap usage
- Temperature
- Power draw
- Thermal throttling
- Notes about shader compilation or stutter

Suggested demanding 3DS testing should use legally obtained personal game data.
